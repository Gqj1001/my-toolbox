# 模板目录 · 使用与维护

## 这里有什么

| 文件 | 作用 |
|---|---|
| `模板-占位符.docx` | **你的 Word 模板原件**（从 `M:\学生文件\templates\` 复制过来的） |
| `parts/` | 模板拆出来的 19 个零件（`word/document.xml`、`styles.xml`、页眉页脚、图片…），仅用于排查问题 |
| `build-template.py` | 构建脚本：把模板内嵌成 `js/template-data.js` |

> 程序**运行时不读这个目录**。真正被网页加载的是 `js/template-data.js`。

---

## 你改了模板之后，必须重新构建

```bash
cd templates
python build-template.py
```

它会做三件事：
1. 把 `模板-占位符.docx` 拆到 `parts/`（方便你看到真实的 XML）
2. 把所有零件以 base64 内嵌，生成 `../js/template-data.js`
3. 打印零件清单、`document.xml` 大小、占位符数量

**然后再刷新网页**（联网版还要 `node setup.js` 重新部署一次，因为 `template-data.js` 要更新）。

## 模板里有哪些占位符（共 263 个）

### 表1 学员基本信息（8 个）

| 占位符 | 含义 |
|---|---|
| `{{name}}` `{{sex}}` `{{school}}` `{{grade}}` | 学生姓名 / 性别 / 学校 / 年级 |
| `{{mgr}}` `{{teacher}}` `{{subject}}` `{{tscore}}` | 学管师 / 教师 / 辅导科目 / 测试得分 |

**「班级」那一格没有占位符**，是标签 + 空格子。程序默认**留白**给你手填；
界面上的「导出时把班级填进 Word」勾选后才写入（默认不勾）。

### 表2 试卷信息（15 个）

| 占位符 | 含义 |
|---|---|
| `{{eyr}}` `{{emo}}` `{{edy}}` | 考试时间的年 / 月 / 日（同一格里，程序会保留"年 月 日"字样） |
| `{{exname}}` `{{exsubject}}` `{{exdur}}` | 考试名称 / 科目 / 时长 |
| `{{extotal}}` `{{exscore}}` `{{exdiff}}` | 试卷总分 / 得分 / 难度 |
| `{{exqual}}` `{{exsrc}}` | 试卷质量 / 试卷来源 → **默认留白**（程序不填，你手填） |
| `{{exam_scope}}` `{{teaching_content}}` `{{progress_points}}` | 考试范围 / 授课内容 / 学生进步点 |
| `{{advice}}` | 教学辅导建议正文（独占一格） |

### 表2 题型分布（30 个 = 6 行 × 5 字段）

`{{tNnm}}` `{{tNct}}` `{{tNdf}}` `{{tNtl}}` `{{tNgt}}`，N = 1…6
（题型名 / 题目数量 / 难度 / 总分值 / 得分）。行数固定 6，不足的行留白。

### 表2 错题分析（210 个 = 30 行 × 7 字段）

`{{qNsn}}` `{{qNtp}}` `{{qNvl}}` `{{qNsc}}` `{{qNdf}}` `{{qNkp}}` `{{qNrs}}`，N = 1…30
（题号 / 题型 / 分值 / 得分 / 难度 / 考察知识点 / 失分情况及原因分析）。

**这里是唯一会动态增删的部分**：
- 试卷 18 题 → 删掉多余的 12 行
- 试卷 35 题 → 复制最后一行的格式，补到 35 行
- 行数变了不会做高度补偿，`trHeight` 保持模板原值（`0` / `atLeast` = 自适应）

## 改模板时的注意事项

1. **占位符名字不要改**，程序按名字找。要加新字段得同步改 `js/report-template.js` 的 `buildMap()`。
2. **不要把占位符拆到两个单元格里**。Word 会把一个 `{{xxx}}` 拆进多个 `<w:r>`（这没关系，程序按段落整体匹配），但如果拆到不同**单元格**里就配不上了。
3. **格式随便改** —— 字体、字号、边框、底纹、行高、列宽、页眉页脚、纸张，程序一个字都不动，只替换文字。
4. **表格数量、列数、合并方式都可以改**，程序不依赖固定列数，只依赖占位符和那两行表头文字（`题号`+`失分情况及原因分析` 用来定位错题区）。
5. 如果留空的行不够（比如试卷有 30 题以上），程序会自动复制最后一行的格式补足，所以 `q30` 之后没有占位符也没关系 —— **但 `q1`…`q30` 必须存在**，否则定位不到。

## 两个模式的关系

`js/report-template.js` 是**首选**（模板模式）。
如果模板加载失败，会自动退回 `js/report-docx.js`（内置渲染器，老实现），保证导出功能不会整个挂掉。
回退时会在界面上提示一条「模板导出失败，已改用内置渲染」。
