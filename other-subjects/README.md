# other-subjects · 其他学科素材暂存区

## 这是什么

「试卷分析工作台」目前只做过**高中数学**的适配（模板、知识点词典、归因规则）。
这个文件夹用来**暂时存放**从其他学科老师那里收集来的原始文件，
等某个学科收齐了，再统一做那个学科的适配更新。

## 目录约定

```
other-subjects/
├── senior/            高中
│   ├── physics/       物理
│   ├── chemistry/     化学
│   ├── biology/       生物
│   ├── chinese/       语文
│   ├── english/       英语
│   ├── politics/      政治
│   ├── history/       历史
│   └── geography/     地理
└── junior/            初中（同样 8 个学科）
```

每个学科文件夹里放**两类**文件，详见该文件夹的 `README.md`：

1. **学科网「试卷分析报告」**（必须有）—— 工具的输入格式，含「细目表分析／知识点分析」那几段
2. **学科网「学生试卷分析表」**（可选，有更好）—— 当反例，避免粘错文件被误解析

## 三条重要约定

1. **原样保留，不要改名、不要转格式。** 我要拿真实文件验证解析器，改过名或转存过就失去验证价值。
   如果同一学科有多份，用 `学科-学校或考试名-日期` 排开即可，文件名不敏感（是我按学科文件夹来归类的）。
2. **这里是纯素材区，不放代码。** 各学科适配的代码产出应在 `public/tools/paper-analysis/` 里。
3. **本目录不会被网站访问到。** 它**不在 `public/` 下** —— 放在 `public/` 里的文件会被 Next.js
   当静态资源，而 `src/proxy.ts` 的 matcher 覆盖 `.docx` 这类未列入排除项的扩展名，
   等于把老师给的材料挂到线上路径上。放在这里既不会被网站访问，也不会误打误撞发布出去。

## 收齐的标准

一个学科要能开始适配，**至少**需要：

- [ ] 1 份完整的学科网「试卷分析报告」（最好 2–3 份不同考试类型：月考 / 期中期末 / 模拟）
- [ ] 该学科的**题型清单 + 每题分值**（见 `docs/other-subjects-plan.md` 的「A 类」说明 —— 这是各科差异最大的一项）
- [ ] 老师的**归因话术习惯**（失分原因怎么写，比如语文的"审题偏差"、英语的"语法点混淆"）
