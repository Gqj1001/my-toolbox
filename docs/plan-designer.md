# 个性化辅导方案设计器（新模板）

页面：`/tools/plan-designer`  
导出模板：`public/templates/plan-designer-template.xlsx`  
课程库（内置数学）：`src/lib/plan-designer-library.json`

示例输出（周子寒，单个工作表）：`docs/examples/plan-designer-sample.xlsx`

## 这版能做什么

- 学生基本信息、当前分/目标分、教师级别
- **辅导周期直接选开始/结束日期**
- **课时与排课由老师自己设定**：
  - 总课时数滑杆
  - 每次课时长（1.5h / 2h / 2.5h / 3h）
  - 在校每周次数、假期每周次数
  - 在校周数、假期周数
  - 国庆加课、其它节日加课
  - 页面实时显示可排次数与总次数是否足够
- **一次导出 1 个 xlsx、1 个工作表**；辅导周期写完整日期范围 + 总课时 + 排课容量。
- 页面支持「收起设置」把左栏收起，表格区域更宽；学情分析默认折叠，先看计划表。
- 课时统一带 `h`：`100h`、`8h`。
- **考向细分**：数列 → 基本量（固定小题约 5 分）/ 通项与求和（大题约 10 分）；
  圆锥曲线 → 基本量（小题 + 大题第一问）/ 综合（大题第二问）；
  其它模块也支持按题位和分值继续拆。
- 前 5 个分析维度按关键词 + 规则生成，可点「AI 润色前 5 项」
- 家庭环境 / 学校环境提供快捷选项，也可手写，不交给 AI 编
- 模块/课程可自由勾选，专门支持预科、插班、只补某几块的学生
- 模块行可上移/下移/删除/新增，规划课时可直接改
- 按所选课程课时 + 高考模块分值权重自动分配总课时，合计实时校验
- 「AI 润色目标」只改目标话术，不改模块/课时
- 模块展开后可勾选**教材级分层**（基础/中档/压轴）的具体知识点，勾选内容会进入“具体知识点”列
- 导出严格使用新 xlsx 模板；「已完成教学效果 / 计划调整」默认 `—`，后续验收时填写

## 课程库

页面里可导入一份课程库 xlsx，浏览器按当前课程库缓存：

- 课程库 sheet：序号 / 知识模块 / 课程名称 / 阶段 / 具体知识点 / 课时 / 教学目标 / 适用层次
- 模块与分值 sheet：知识模块 / 高考分值 / 含课程 / 说明

内置的数学课程库来自 `M:\高中数学\08_特殊学情专区\辅导方案\寒假集训-2027\寒假集训课程库.xlsx`。

## 已知边界

- 目前只做数学；多学科需要增加学科课程库与分值表。
- 课程库缓存在浏览器 localStorage，换电脑/换浏览器需要重新导入；后续可做到数据库共享。
- 学习分析的前 5 项 AI 润色是会员功能，非会员仍可用规则文本 + 手动修改。
