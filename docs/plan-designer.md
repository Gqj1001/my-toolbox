# 个性化辅导方案设计器（新模板）

页面：`/tools/plan-designer`  
导出模板：`public/templates/plan-designer-template.xlsx`  
课程库（内置寒假集训）：`src/lib/plan-designer-library.json`

示例输出（周子寒 2027 寒假阶段，40h，18 行）：`docs/examples/plan-designer-sample.xlsx`

## 这版能做什么

- 学生基本信息、当前分/目标分、总课时、已上课时、教师级别
- 四个窗口期自动生成辅导周期与周课时：
  - 3 月 → 春季学期
  - 7 月 → 暑期集训
  - 8 月 → 秋季学期
  - 12 月 → 寒假集训
- **三种出方案方式**：
  - 窗口期报名：一次出连续两个阶段（12 月 = 寒假 + 春季，3 月 = 春季 + 暑期……）
  - 学期中途入学：只出当前阶段（4 月 = 春季）
  - 全托生：从当前窗口起连续四个阶段
- 阶段课时可以自己填（逗号分隔）；不填默认两阶段 40% / 60%，全托四等分。
- 每个阶段单独导出一个 xlsx（文件名带阶段名），避免一期方案混在一起。
- 课时统一带 `h`：`100h`、`8h`、`6h/周`。
- **考向细分**：数列 → 基本量（固定小题约 5 分）/ 通项与求和（大题约 10 分）；
  圆锥曲线 → 基本量（小题 + 大题第一问）/ 综合（大题第二问）；
  其它模块也支持按题位和分值继续拆。
- 前 5 个分析维度按关键词 + 规则生成，可点「AI 润色前 5 项」
- 家庭环境 / 学校环境由老师手填，不交给 AI 编
- 模块/课程可自由勾选，专门支持预科、插班、只补某几块的学生
- 模块行可上移/下移/删除/新增，规划课时可直接改
- 按高考分值权重 + 所选课程课时自动分配总课时，合计实时校验
- 「AI 润色目标」只改目标话术，不改模块/课时
- 导出严格使用新 xlsx 模板；「已完成教学效果 / 计划调整」默认 `—`，后续验收时填写

## 课程库

页面里可给**当前窗口期**单独导入一份课程库 xlsx，浏览器会按窗口缓存：

- 课程库 sheet：序号 / 知识模块 / 课程名称 / 阶段 / 具体知识点 / 课时 / 教学目标 / 适用层次
- 模块与分值 sheet：知识模块 / 高考分值 / 含课程 / 说明

内置的寒假集训库来自 `M:\高中数学\08_特殊学情专区\辅导方案\寒假集训-2027\寒假集训课程库.xlsx`。  
春季 / 暑期 / 秋季需要各自导入对应课程库。

## 已知边界

- 目前只做数学；多学科需要增加学科课程库与分值表。
- 课程库缓存在浏览器 localStorage，换电脑/换浏览器需要重新导入；后续可做到数据库共享。
- 学习分析的前 5 项 AI 润色是会员功能，非会员仍可用规则文本 + 手动修改。
