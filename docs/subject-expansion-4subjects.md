# 全学科扩展（辅导方案侧）· 四学科差异分析

> 用户 2026-10 长任务：「通用辅导方案生成器」从**物理一个学科**扩到**四个学科**
> （初中数学、英语初高中、语文初高中）。
>
> 本文只讲**差异**：哪些能直接复用、哪些必须改、发现了什么"不看样例就想不到"的事。
> 实做记录见 `docs/plan-generator-plan.md`；给老师的名单见各 `docs/*-module-list-draft.md`。

---

## 0. 一句话结论

**四个学科可以装进同一个工具**，而且**只有语文需要特殊判断**（它有两种模板形态）。
其余三个学科（物理 / 数学 / 英语）**共用同一套模板与导出链**，一份代码都不用改。

**最重要的发现**：老师给的样例里，**同一个学科也可能有两套表结构** ——
语文的"辅导方案"就有两种（附件3 同款 4 列 / 另一套 6 列）。
所以"读样例"这件事不能停在第一份，必须**把该学科所有样例都扫一遍**。

## 1. 表结构对比（这是"能不能复用模板"的唯一判据）

| 学科 | 学段 | 进度表列 | 与物理模板的关系 |
|---|---|---|---|
| 物理 | 初/高 | 阶段（章节/单元/模块）· 内容（包括阶段检测）· 课时数 · 教学目标 | **基准** |
| **初中数学** | 初中 | 同上（4 列，逐字一致） | ✅ 可直接复用 |
| **英语** | 初/高 | 同上（4 列，逐字一致） | ✅ 可直接复用 |
| **语文** | 初/高 | **两种形态**：① 附件3 同款 4 列（知识模块·具体知识点及目标·课时数·效果评估）② 另一套 **6 列**（阶段·内容·课时数·教学目标·**孩子分数**·**高考分值**） | ⚠️ 见 §3 |

> 📌 **判据**：只看"进度表列名与格数"。列不同 ⇒ 模板不能共用；
> 列相同 ⇒ 抬头/字体/表头这些细节**都可以沿用**（四个学科的抬头字段本来就都是
> 「学员 / 年级 / 学科 / 教材版本 / 学校 / 学管师 / 咨询师 / 教师」这一套）。

## 2. 可以**直接复用**的东西（占 90%）

| 复用项 | 说明 |
|---|---|
| **一行一模块的引擎** | 数学/英语/语文的样例本来也是"一个模块一行"（章节轴 / 单元轴），与物理同构 |
| **课时分摊（保小数、总和精确）** | 数学样例里有 1.5 / 4.5，英语有 2 / 4 / 6，语文有 2 / 4 / 12 —— 引擎原生支持 |
| **本工具 Word 模板** | 4 列表头逐字一致 ⇒ 一套模板装三学科（抬头里的"学科"由程序填） |
| **公司附件3 导出** | 同一个引擎、同一套取数；**未改动** |
| **存档案** | 同一个接口、同一套合并语义；学科靠 `subject` 区分 |
| **界面** | 学科/学段/年级三个下拉都是"读清单"的，加学科**界面代码一行不改** |
| **AI 路由的护栏** | 鉴权/行数契约/不透传/关思考模式，全学科通用 |

## 3. 语文：唯一的例外（也是本轮最值得记的事）

### 3.1 它有两种形态

| 形态 | 出现在 | 进度表 | 处理 |
|---|---|---|---|
| **A · 附件3 同款 4 列** | `junior/chinese/辅导方案/李立柱开学辅导计划.docx`（39h / 9 模块）<br>`senior/chinese/辅导方案/李世扬辅导方案.docx`（一轮 92h + 二轮 30h + 三轮 22h）<br>`senior/chinese/辅导方案/郭禹瑄辅导方案模板.docx`（北京卷） | `知识模块｜具体知识点（含检测）及预期目标｜课时数｜效果评估` | ✅ **本轮走这个** |
| **B · 另一套 6 列** | 上面后两份的**头部区块** | `阶段｜内容｜课时数｜教学目标｜孩子分数｜高考分值` | ⚠️ 不进进度表 |

### 3.2 为什么选 A 而不是 B（要记录判断依据）

- **A 与其它三个学科的表头逐字一致** ⇒ 共用模板、共用导出链、共用测试；
- B 多出来的两列语义**各有归宿**，不需要新开列：
  - 「**孩子分数**」= 过程数据（每行的得分情况）——**工具没有这个数据来源**，
    按项目红线"没有数据来源的格一律留空给老师写"，**不进表**；
  - 「**高考分值**」= 该模块在卷面里的分值（静态信息）——**写进「内容」列末尾**即可，
    老师样例本来就是这么写的（例：「…专题练习+讲评+阶段小测」+「19分」）。
- 代价：老师若更爱 B 那张表，要在 Word 里自己加两列（工具导出的仍是 A）。
  **这条写进了报告，等用户/老师拍板**。

### 3.3 语文的"话术"也是两段式

从样例里看出来的固定写法（已写进 `prompts.ts`）：

```
知识点：120 个重点实词、18 个虚词、特殊句式。
目标：落实文言基础，读懂浅易文言文；翻译做到直译落实重点字词；搞定断句、常识、概括类题型。
重点与难点：实词推断的方法与句式判断，翻译的采分点落实。分值：高考 20 分。
```

⇒ 物理那套「知道/理解/掌握」不适合语文，所以**措辞规则按学科参数化**（英语同理，见 §4）。

## 4. 英语：**单元轴** + 两段式话术

| 项 | 与物理的差异 | 处理 |
|---|---|---|
| 编排轴 | 物理按**章节**，英语按**单元**（Unit） | 模块 = 一个单元（与老师样例一致） |
| 每模块课时 | 物理 1.5–15h，英语 2–6h（一个单元 2–4 课时） | 照样例 |
| ⭐ **跨册重名** | 「Unit 1」在必修一/二/三里**都有** | **必须带册次**（「必修三 Unit 1」）—— 否则附件3 会按名字合并行、**静默少行** |
| 话术 | 老师固定写「语言模块：…；语法模块：…」（初中）/「核心词汇与重点句型…；语法要点：…」（高中） | 写进 `prompts.ts` 的英语分支 |
| 未读到的样例 | 3 份老 `.doc`（含**高三全年**那份） | 不影响模块划分（教材轴一致）；但**高三课时口径**没抄到，本表用"每单元 2 课时" |

---

## 5. 初中数学：只做初中（**刻意的**）

| 项 | 说明 |
|---|---|
| 范围 | **只做初中**。高中数学已经有 `math-plan`（数学老师每天在用），而它是**"一行一次课 + 2 课时粒度"**，与本工具"一行一模块"**口径不同** |
| 为什么不合进来 | 合进来等于让老师面对两套口径；用户本轮也只要求"初中数学" |
| 模块轴 | 七/八/九年级六个学期（章节轴）+ 中考一轮 12 个专题 + 冲刺 4 个收口 |
| 满分/档位 | 初中数学多按 **120 分**（河北中考）⇒ 档位线 100/72/0（**不是**数学版的 150 分制） |
