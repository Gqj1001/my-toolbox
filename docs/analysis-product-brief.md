# 「学情分析」产品说明（介绍产品时可以直接照着讲）

> 用户问的是：**学情分析分两部分，功能特点怎么讲清楚？**
>
> 一句话先记住：
> **上半部分 = 免费的"账本"（把已有记录算成数字，不猜）；下半部分 = 会员的"大夫诊断"（AI 把这些数字写成一段话）。**

---

## 一、它在产品里的位置（一句话）

学情分析挂在**每个学生的档案详情页**（`/dashboard?name=学生名`），
是"这个学生到目前为止到底怎么样"的**唯一汇总入口** ——
不用再去翻辅导方案、试卷、课后反馈三个工具。

**它不产生新数据，只消化已有数据。** 这是它最值钱、也最容易被误解的一点：
它不是又一个"要你填东西"的功能，而是**你已经干过的活，自动变成结论**。

---

## 二、上半部分：📊 学情分析（免费，人人都有）

### 特点（讲的时候按这四条说）

| # | 特点 | 为什么这是卖点 |
|---|---|---|
| 1 | **零录入** | 不用填任何新东西。三个工具（辅导方案 / 试卷分析 / 课后反馈）以前存的记录，它自动汇总 |
| 2 | **只算不猜** | 页面上写死了"依据档案里已有的记录自动汇总，**不含推测**"。抽不到的说"抽不到"，不编 |
| 3 | **能看出趋势，不只看一次分** | 成绩趋势按**日期**排（哪天考的、什么卷子、得分率多少），首末变化、平均、最高最低都列出来 |
| 4 | **薄弱点用老师自己的原话** | 「薄弱与失分」里每一条都标着**来自哪个工具、哪一天、哪份材料**，是老师当初写的原话，不是 AI 另行总结 |

### 它具体显示六块（对着截图讲）

1. **概览**：共几条记录、分别是哪类（方案/试卷/反馈）、时间跨度多少天。
   → 用途：一眼看出"这个学生的档案厚不厚"，也能发现"哦，他三个月没新记录了"。
2. **成绩趋势**：一张小表（日期 / 名称 / 来源 / 得分 / 得分率）+ 一句话总结
   （首次 ×% → 末次 ×%（涨跌几个百分点）；平均；最高；最低）。
   → 用途：**涨了还是掉了，不用自己算。** 得分率是为了把 100 分卷和 150 分卷放在一条线上比。
3. **分数目标对比**（2026-10 新增）：把辅导方案里的「提分目标 A → B 分」和考试记录放在一起，
   写清初始分 / 本次分 / 目标分、还差多少、较首次提升多少、大约每月提升多少。
   方案没写目标分或没有带满分的考试记录时，**明确说无法对比**（不自己设目标）。
4. **学习进度**（2026-10 新增）：从最近一次课后反馈的【课堂内容】/【下节课内容】看"现在学到哪"，
   再对照辅导方案的【逐次课表】/【阶段安排】，说清进行到第几条/共几条；对不上时明说"方案可能已调整"。
5. **课时安排**：从辅导方案正文里读「共 N 课时」，累加出"这学生一共排过多少课时"。
   → 用途：课时投入与分数变化能对照着看（投入产出比）。
6. **薄弱与失分**：把各份材料里写过的薄弱点**逐条摘出来**，带来源与日期。
   → 用途：这是**下一份方案的依据**。不用再翻旧文件找"上次说他哪儿弱"。

### 它明确**不**做的事（讲的时候主动说，反而加分）

- 不猜分数：材料里没写满分，就算不出得分率，那一行就不进趋势（并在底部小字里说明"有 N 条没计入"）。
- 不做归因：它不会说"因为他不努力所以掉了"。
- 不合并不同科目：得分率是把不同卷子放在一起看的，**跨科目比较没有意义**，所以它是单科档案视角。
- **没日期也能算**：没有日期的记录用"存进来的时间"兜底排序，**不会因为缺日期就被丢掉**
  （这一点是 2026-10 用户反馈后专门加固的，见 `docs/plan-generator-plan.md` 与 `tests/student-report.test.mjs`）。

## 三、下半部分：🤖 AI 整体学情报告（会员专属）

### 特点

| # | 特点 | 为什么这么设计 |
|---|---|---|
| 1 | **AI 只读上面的账本** | 提示词里写死了"只依据上面这些已经存在的记录来写，材料里没有的不会编"。它拿到的输入就是上半部分那份结构化数据，不是原始聊天 |
| 2 | **一次生成 = 一条档案记录** | 每点一次，档案里就多一条「学情报告」（`tool='analysis'`）。所以：**能留档、能对比、能删**（列表里有删除按钮） |
| 3 | **生成要花钱，所以是会员专属** | 上半部分免费 —— 因为没有 AI 调用，只是算数 |
| 4 | **和"手动补录"共存** | 老师补进来的历史材料（老 Word/PDF）也会被算进去，AI 报告一样用得上 |

### 它给的是"人话结论"，不是数字

上半部分回答「是多少」，AI 报告回答「所以呢、接下来怎么办」。
定位是**给老师写初稿**：像一份可以念给家长听、也可以直接带去机构学情分析会的小结，
老师改几句就能用，而不是让 AI 直接面向家长。

### 报告固定六个部分（2026-10 升级）

【整体学情】【学习进度】【分数目标对比】【优势】【薄弱与原因】【针对性提升方案】

- **学习进度**：按时间轴说清"目前学到哪、复习到哪个模块"，并对照方案课表；
- **分数目标对比**：初始分 / 本次分 / 目标分 / 差距 / 提升速度；
- **针对性提升方案**：分点写"练什么 → 怎么练 → 达到什么标准 → 什么时候检查"，贴下一步教学计划；
- 提示词要求 **像老教师一样推理**：每个判断带依据（哪次考试/哪条反馈/方案哪一条），
  把"之前—现在—为什么—下一步"串起来，不是罗列数据。
- 材料不足（没目标分、没反馈、对不上课表）时，**明确说无法判断**，不硬编。

## 四、两部分的分工（这张表最好记）

| | 📊 学情分析（免费） | 🤖 AI 整体学情报告（会员） |
|---|---|---|
| 干什么 | **算**：把记录变成数字与清单 | **写**：把数字写成结论与建议 |
| 谁都能用吗 | 是，所有人 | 否，会员专属 |
| 花不花钱 | 不花（纯计算） | 花（调用大模型） |
| 会不会留档 | 不留（每次现算） | **留一条记录**（可删、可对比） |
| 会不会编 | **不会**（只做加减） | 规则上不许编，但**措辞是它写的**，要人核 |
| 出错了怎么办 | 数字错 = 数据错，去改记录 | 不满意 = 重新生成，或直接改正文 |

---

## 五、给客户讲的三句话（可以直接背）

1. **"您平时做的每一份方案、每一张卷子分析、每一次课后反馈，都会自动变成这个学生的学情账本 —— 不用再额外填表。"**
2. **"账本这部分不猜、不编，材料里没写的它就明说没写；所以您给家长看数据是有底气的。"**
3. **"会员多一步：让 AI 把这本账写成一段能直接讲给家长听、也能带去机构学情分析会的学情小结，一次生成、留一条档、不满意可以重生成。"**
4. **"开会的三个问题它都替您先答了：现在学到哪（学习进度）、离目标还差多少（分数目标对比）、下一步具体怎么练（针对性提升方案）。"**

---

## 六、这套东西的边界（诚实记录，别在介绍时说过头）

- **数据密度决定报告质量**：只有 1 条记录时，AI 报告会很短、很保守 —— 这不是 bug，是"没料"。
- **跨科目不做合并**：一个学生如果同时补数学和物理，两科的档案是分开看的。
- **AI 报告需要人核**：它是初稿。项目里所有 AI 功能都挂在"老师核对后用"这个前提上。
- **"不给没数据的东西编数"是硬约束**，有测试钉着（`tests/student-report.test.mjs` 的"抽不到就说抽不到"组）。
- **学习进度是"按材料对照"的**：它拿最近一次反馈的【课堂内容】去匹配方案课表；匹配不上会明说
  "方案可能已调整，请人工核对"，**不会硬说成按计划**。所以反馈正文最好保留【课堂内容】标记。
