## 0. 一句话

一个新工具 `/tools/plan-generator`：老师选**学科 + 学段 + 年级 + 总课时 + 学生情况** →
工具按**确定性规则**算出「模块取舍 + 课时分摊」并出一张**一行一模块**的进度表 →

`math-plan`（数学专用版）**一个字节都不动**。

## 2. 三条铁口径（用户拍板，别再改回去）

1. **一行 = 一个模块**，课时写**模块总课时**。
   **不抄** `math-plan` 的 `buildLessons()`（那是"一行 = 一次课 2 小时"）。引擎里根本没有拆次课的函数。
   > ⚠️ **2026-10 用户线上验收后改了课时口径（原口径作废）**：
   > 原来是"保留一位小数（4.5 / 7.5 / 10.5）"，用户看到课表里出现 `1.5 / 3.1 / 4.6` 后明确要求
   > **「课时一律整数，多为偶数，余数处理成 1」**。
   > 现行口径（`engine.js` 的 `spreadInts`）：
   > · 每行 ≥ 1、≤ 建议课时 × 2（上限不变）；
   > · **优先按 2 的倍数分摊**：总课时是偶数 ⇒ **一行奇数都没有**；
   > · 总课时是奇数 ⇒ **恰好一行**是奇数（多出来的那 1 课时给"最该多拿"的那行）；
   > · 合计仍**精确等于**总课时；老师填了小数总课时（80.5）⇒ 取整成 81 并在提示里明说。
   > · 科目包里的 `hoursHint` 也全改成了整数（.5 用银行家舍入：4.5→4、7.5→8、1.5→2）。
2. **凡是工具里没有数据来源的格，一律留空给老师写，不许 AI 编。**
3. **AI 只做文字活**：模块取舍与课时分配是**确定性规则**（纯函数、可单测），不交给模型。

## 4. 引擎（`js/engine.js`）· 本轮已完成

纯函数、学科无关、Node 可直接 `require`。对外能力：

| 函数 | 干什么 |
|---|---|
| `modulesForGrade(pack, grade)` | 这个年级能排哪些模块（科目包的 `grades` 表；认不出就全部，**宁多勿少**） |
| `bandOf / bandKeyOf(pack, score)` | 档位线**按科目包**（物理 100 分制，不沿用数学的 150 分制） |
| `scoreModule / selectModules` | 模块取舍：档位 × 难度 × 标签 × 薄弱点 + 必开豁免；**预算感知**（选进来的模块总体塞得下） |
| `allocateHours(modules, 总课时)` | 课时分摊：保留一位小数、**总和精确等于总课时**、每行 [1, 建议课时×2] |
| `buildPlan(pack, opts)` | 组装整份方案（模块行 + 阶段 + 给老师看的提示 notes） |
| `groupByStage / stageNameOf` | 按复习阶段分组（附件3 的「阶段」列用） |
| `selfCheck(plan)` | 核账：合计对不对、有没有重名模块（附件3 会合并同名行） |

### 4.1 课时分摊的口径（这里最容易做错，两次都踩了）

**正确做法**：`权重 = 建议课时` → **定标**（求最大的系数 k 使 Σ clamp(round(k×权重), 1, 建议×2) ≤ 总课时）
→ 收上下限 → **把零头补给"离自己额度差得远"的行** ⇒ 总和精确、比例关系不被打乱。

| 走过的弯路 | 症状（实测） |
|---|---|
| ❌ 先按比例、再逐行收上限 | 老师填 60 课时，只排进去 37.6，**剩下 22.4 课时无处可放** |
| ❌ 把"建议课时"直接当初始分配、再拿预算补差 | **平均主义**：9/6/3 三个模块配 30 课时变成 10.3/10/9.7 |
| ❌ 从"1 课时/模块"估算能选多少模块 | 总课时 28 时按下限能选 25 个模块，但配平时每行有上限 ⇒ **只落地 25，差 3 课时** |

### 4.2 本轮测试抓出的三个真 bug（都已修 + 都已加钉子）

1. **`toTenths()` 套了两层** ⇒ 单行上限变成"建议课时的 20 倍"（等于没有上限）。症状：47.3 课时配出 23.6/15.8/7.9。
2. **选模块只看下限**（见上表第三行）。
3. **配平时又给每行夹了一个 `totalT` 上限** ⇒ "最小模块"的额度被锁死在自己的建议值上，240 课时只排得进 25。

### 4.3 测试与变异自证

`tests/plan-generator-engine.test.mjs`（**纯函数，不需要服务/浏览器**）：**40 项全绿**。
其中 5 条**变异自证**（把真 bug 装回去必须变红，且要红到"对的那条"断言）：

| 变异 | 结果 |
|---|---|
| A 课时抹成整数（丢掉 4.5 / 7.5 小数） | 红 2 条，含「一位小数」✅ |
| B 退回「一行 = 一次课」（按 2 课时拆行） | 红 6 条，含「一行」✅ |
| C 已完成的模块照排 | 红 1 条，含「已完成」✅ |
| D 拿掉「建议课时 × 2」的上限 | 红 2 条，含「上限」✅ |
| E 配平不把总量补齐 | 红 2 条，含「精确等于」✅ |

> 📌 **一条诚实的记录**：本来想钉"按比例补零头 vs 按差额补零头"，结果查下去发现
> **在上下限之内两者结果完全一样**（6 个花色的物理包都是 18/12/6）⇒ **那不是真 bug**，
> 所以换成了"总量必须补齐"这个真红线。变异跑出全绿时先去读断言，别硬凑。

### 10.2 为什么必须给它补测试（原来一套都没有）

这个文件是"导出件能不能被 Word 打开"的地基，而它出错时**页面上没有任何报错** ——

| 检查项 | 谁来验 |
|---|---|
| ZIP 结构、CRC 校验和、成员是否齐全 | **Python 的 `zipfile`**（`testzip()` 会自己校验 CRC） |
| CRC32 算法 | 与 **Node 内置 `zlib.crc32`** 对拍（7 例，含中文）+ 标准向量 `0x CBF43926` |
| 中文内容逐字保留（姓名 / 章节串 / `≥95%`） | Python 解出 `word/document.xml` 后**逐字 find** |

| 重复 build 字节完全一致 | 逐字节比对两次产物 |

**变异自证 2 条**：① 中央目录不写 UTF-8 标记 ⇒ 红；② 产物改坏一个字节 ⇒ Python 报 CRC 错 ⇒ 红。

> 📌 三条措辞/写法上的记录（都是本轮真踩到的，免得后人重复）：
> ① `table()` 收的是 `{cells, opts}` 对象数组，**不是**裸二维数组（第一版传错，`cells.join is not a function`）。
> ② 断言行数时 `<w:tr>` **不带空格**（第一版按 `<w:tr ` 数，数出 0 行）。
> ③ 变异"去掉 UTF-8 标记"第一次改错了地方 —— ZIP 的标记在**中央目录**里才是权威，
>    只改本地头文件那一份 ⇒ Python 照样读到 `flag=true`，**变异假 MISS**。
>    变异不红时先去读自己改的是哪一行，别急着说"这段代码无所谓"。

## 11. ✅ 实做记录（AI 生成教学目标）

### 11.1 与数学版**不一样**的一个决定（要记住）

**AI 只生成「教学目标」，不生成「内容」。**
数学版的 AI 是"分区润色"（原文 → 改写）；新工具这里，**"内容"那一列由程序填**
（科目包里的教材真实小节号，照人教社目录），AI 只写"学完之后能做到什么"。

理由：让模型写内容，它**必然编造章节号**（比如凭空写个「4.7 牛顿定律的应用」），
而导出件是给家长看的。所以"内容"这件事从数据结构上就不交给模型。
用户原话也是"教学话术由 AI 生成初版 + 老师就地编辑"——话术就是**教学目标**。

### 11.2 提示词怎么做到"像老师写的"（用户明确要求的那一条）

我从老师给的 **5 份真实辅导计划**里提炼出写「教学目标」的固定套路，写进提示词：

| 套路 | 来自样例的写法 |
|---|---|
| 分点用「知道 / 理解 / 掌握 / 会 / 能」起头 | 「知道质点的概念…理解参考系的概念…」 |
| 高中收尾加「**重点与难点：**」+「**分值：**高考必考知识，每年的分值在 N 分到 M 分不等」 | 全年班组样例每一条都这么收尾 |
| 初中偏「**重点：**」+ 落到"会解释现象 / 会用公式算 / 会做实验" | 初三全托样例的写法 |
| 量化指标（正确率/得分率） | 「正确率≥90%」「每题不超过 2 分钟」 |

并把**真实样例原文**作为 few-shot 风格示范（3 条，含 1 条实验模块的写法），
同时明确写「只是风格示范，不要照抄内容」——免得模型把样例里的模块名/分数抄进本次结果。

### 11.3 护栏（与数学版逐条对齐，一条不少）

| 护栏 | 为什么 |
|---|---|
| `requireVip()` → 未登录 401 / 封禁 403 / 非会员 403 | 与其它三个 AI 功能同一口径 |
| 没有 `AI_KEY` → **503** | 让老师看到"服务端没配"，而不是一句"失败" |
| 关思考模式 + `truncatedByReasoning` 重试一次 | 线上真踩过：reasoning 吃光 max_tokens、正文为空 |
| **行数契约**（服务端 + 客户端**各校验一次**） | 错位的目标贴到别的模块上，老师基本发现不了 |
| 上游错误**不透传**（前端只说"暂时不可用"） | 上游原文可能含 key/账户信息 |
| 响应里**绝不出现** `AI_KEY` | 同上 |
| 清掉行首编号与包裹引号 | 模型爱加「1. 」「第1条：」 |

### 11.4 客户端最要紧的三条（都有变异自证）

1. **行数对不上就整批放弃**（宁可不填，也不贴错位）；
2. **默认只填空行，不覆盖老师写过的**（AI 是来打草稿的，不是来改老师的稿）；
3. **不改原数组**（`applyGoals` 返回新数组）—— 一个批次失败时**保留已成功的批次**，
   不整批回滚（回滚等于白花已经付钱的那次调用）。

### 11.5 测试与自证

| 套件 | 项数 | 覆盖 |
|---|---|---|
| `tests/plan-generator-ai.test.mjs` | **38** | 11 项提示词纯函数（参数化/量化表/行数契约/few-shot）+ 8 项静态护栏 + **19 项真服务**：401/403/200/行数不匹配 502/上游 500 不透传/空正文 502/Key 不回传/入参 400×4/413/单条重写 |

```
正文标题            {{title}}

抬头 r00 tc4         {{subj}}       学科值
```

### 12.3 五道自检（都是"不报错但会静默出错"的检查）

| # | 检查 | 为什么 |
|---|---|---|
| ① | 11 个占位符一个不少 | 少一个 ⇒ 导出件那一格永远是空的 |
| ② | 进度表**只剩 1 行样板行** | 残留样板行 ⇒ 导出件里多出无关的行 |
| ③ | **样例文字零残留**（"锐满分/王宇晨/213h/运动的描述/1.1质点/2026年9月/一轮专题复习/高考真题"） | 老师的样例内容漏进导出件 = 给家长看错东西 |
| ④ | 表头/抬头标签还在 | math-plan 历史上把标签格覆盖掉过一次（导出成"只剩值、标签不见了"） |
| ⑤ | 占位符落在**单个 run** 里、且同一格里**不重复** | 被拆散 ⇒ 替换不上；重复 ⇒ 导出件里同一个值写几遍 |
| ⑥ | 格式类零件（styles/theme/fontTable/settings/rels/Content_Types）**内容等价** | 证明只改了 `document.xml` 的**文字** |
| ⑦ | 产物是**结构完好的 docx**（zip CRC + 每个 XML 可解析 + 根元素是 `w:document`） | Word 打不开就全白干 |

### 12.4 造模板时踩到的 4 个坑（都修了，都写进脚本注释）

1. **表头下面还有"阶段分隔行"**（样例里的「二轮大专题复习：…」）—— 只按"≥4 格"筛数据行会把它漏掉
   ⇒ 样例文字残留。真判据是"**里面有没有占位符**"。
2. **一个格里把每个 run 都写成占位符** ⇒ 同一格出现 4 个 `{{s1_ct}}`。
3. **只认"第 1 段的第 1 个 run"** ⇒ 抬头那几格的**值是第 2 段**，首段是空 run，
   结果把年级值写空了（`{{grade}}` 丢失）。
4. **"格式零件逐字节不变"这条断言本身是错的** —— `python-docx` 保存时会重写整个包
   （XML 声明、标签间空白、属性顺序、甚至连 `[Content_Types].xml` 里 `<Default>` 的顺序都会变）。
   改成比**归一化后的 XML**（去声明/去注释/压空白/**顶层元素排序**）。
   ⚠️ 最后那个"排序"也是被逼出来的：不排序时 `[Content_Types].xml` 会假红一次。

### 17.2 ⭐ 这一批最值得记的两个坑

**坑 1：改口径会影响"选模块"，不是只改输出。**
课时从"小数、可给 0.5"变成"整数、优先偶数"之后，`selectModules` 里那句预算估算
（`weightOf`）也必须跟着改，否则会**选进一堆模块却只给得起 1 课时**：

- 实测：英语（每单元建议 2 课时）75 课时按旧估值（`hint/2` ⇒ 1）选进 **48 行**，
  结果 **21 行只有 1 课时** —— 既违背"多为偶数"，也让"一个单元 1 课时"显得假；
- 改成 `max(2, round(hint/2))`（**至少按"一对"估**）后：75 课时 → 32 行、最多 1 行奇数、**没有一个 1 课时**。

> 教训：**改输出口径时，要顺着数据流往上找"有没有别处按旧口径估过账"**。
> 这条写进了 `engine.js` 的注释和一个专门的变异（A3）。

**坑 2：`op:"setDate"` 的第一版写在「缺学生姓名 → 400」之后 ⇒ 每次都被顶回去。**
因为 `setDate` 是按**记录 id** 定位的、不带 `name`。
自测时看到的是 `{"ok":false,"error":"缺少学生姓名。"}` —— 一眼就能看出"分支没走到"，
