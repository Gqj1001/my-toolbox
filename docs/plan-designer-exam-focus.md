# 考向细分 · 高考校准表（待与老师逐题确认）

> 当前程序里的考向分数/题位是**首版估算**，来自新高考 I 卷常见分布和老师给的 2027 寒假样例；
> 还没有用官方考纲 + 近五年真题逐题统计校准。下表用于今晚逐项确认。

## 一、已拆分的重点考向

|---|---|---:|---|---|

## 二、近五年逐题统计要填的字段

每个考向至少统计：

1. 年份 / 卷型（新高考 I 卷、北京卷等）
2. 题号
3. 题型（单选 / 多选 / 填空 / 解答）
4. 分值
5. 考查载体（公式、图像、实际情境、新定义）
6. 关键步骤 / 易错点
7. 与教材模块的对应关系

## 三、校准后的落地方式

- 修改 `src/lib/plan-designer.ts` 里的 `EXAM_FOCUS`（分值、题位、说明）。
- 如某个考向跨模块，拆成两条并标注“跨模块重叠计分”。
- 修改后重新生成一次示例，检查表格里的：
  - 考试分值列
  - 可达成的目标里的“目标得分”
  - 课时分配权重
